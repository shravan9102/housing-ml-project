## Dataset Details

- Number of records: ~20,000
- Dataset type: Tabular housing data
- Includes numerical and categorical features
- Target variable: median_house_value

# Housing Price Prediction (Machine Learning)

This project predicts housing prices using a machine learning pipeline.
The model is trained on approximately 20,000 housing records.

## How to Run
1. Install dependencies:
pip install -r requirements.txt

2. Train and predict:
python main.py
